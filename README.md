# Testing Assignments

This repository contains software development, software testing and
data analysis assignments. Each project has its own directory.

## Projects

### 1. Unit Testing

A JavaScript project demonstrating unit testing with Mocha and Chai.

The tests check arithmetic operations, input validation and error
handling.

### 2. Integration Testing

A JavaScript project demonstrating a hex-to-RGB conversion library
and an Express REST API.

Includes unit tests, automated API integration tests and manual
request checks using cURL.

### 3. EV Charging Data Analyzer

A Python project that analyses electric vehicle charging data using
pandas and matplotlib.

Large source datasets are excluded from the repository.

### 4. Website Testing

A website testing assignment using Amazon.

Includes:
- Browser developer tools for mobile screen emulation.
- CPU and network throttling.
- Performance recordings and observations.
- Selenium WebDriver automation of browser interactions.
- Screenshots and discussion of possible improvements.

### 5. UI Testing

A basic colour converter built with HTML, CSS and JavaScript.

Features:
- Hex-to-RGB conversion.
- RGB-to-hex conversion.
- Input validation and clear error messages.
- A colour preview that updates after valid conversions.
- A responsive layout and keyboard navigation.

Testing includes:
- Manual GUI checks with valid, invalid and boundary inputs.
- 14 automated Selenium WebDriver tests organised with Mocha.
- Assertions for conversion results, validation messages and preview
  behaviour.
- Screenshots and a report using the LAB thesis template.

## Running the Projects

Open the relevant project directory and follow its README for setup
and execution instructions.

For the UI Testing project:

    cd "UI Testing"
    npm ci
    npm test

Open its index.html file in a browser to use the application.

## Purpose

The repository organises coursework projects in one place and
demonstrates different approaches to software testing, browser
automation and data analysis.
