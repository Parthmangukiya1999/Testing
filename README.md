# Testing Assignments



This repository contains software development and data analysis assignments.



## Projects



### 1. Unit Testing



A JavaScript project demonstrating unit testing and automated tests using Mocha and Chai.



### 2. Integration Testing



A JavaScript project demonstrating API integration testing and automated endpoint tests.



### 3. EV Charging Data Analyzer



A Python project that analyses electric vehicle charging data using pandas and matplotlib.



## Technologies



* JavaScript and Node.js

* Mocha and Chai

* Python

* pandas and matplotlib

* Git and GitHub



## Purpose



The purpose of this repository is to organise coursework projects in one place while keeping each project in its own directory.
